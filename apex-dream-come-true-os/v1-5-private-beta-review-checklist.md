# v1.5 Private Beta Review Checklist

Status: DRAFT / REVIEW-GATED
Truth status: NOT DEPLOYED / NOT VALIDATED

## Private Beta Rule

Do not open a public beta until these gates are complete.

## Review Gates

### Product
- Dream intake works locally.
- Pathway output is understandable.
- SWOT output is labeled as draft guidance.
- Resource suggestions are framed as research tasks unless verified.

### Privacy
- No sensitive data required for initial demo.
- Any minor workflow requires appropriate adult review.
- No private data included in public share cards.
- Retention and deletion approach documented.

### Safety
- No guaranteed dream fulfillment claims.
- No automatic external outreach.
- No direct child external sharing.
- False hope risks are visible.

### Accessibility
- Keyboard navigation reviewed.
- Color contrast reviewed.
- Screen-reader labels reviewed.
- Mobile layout reviewed.

### Security
- No secrets committed.
- No production endpoints in static prototype.
- No live sending functionality.
- Incident response draft exists before real users.

### Evidence
- Each beta claim has a ledger entry.
- Each pilot result is separated from marketing language.
- Feedback is captured without overstating validation.

## Private Beta Exit Criteria

- 5 to 10 trusted adult reviewers complete review.
- No critical safety/privacy defects remain.
- No external outreach is sent by the system.
- Feedback ledger is created.
- Next build is scoped from evidence, not excitement.
