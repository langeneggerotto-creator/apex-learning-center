# GitHub Submission Checklist

## Completed in this draft layer

- Draft branch prepared
- README included
- Status boundary included
- No-send policy included

## Required before merge

- Confirm target repo is correct
- Review license and IP policy
- Review privacy posture
- Review accessibility posture
- Confirm no secrets or private data included
- Confirm prototype has no live sending functionality

## Required before public launch

- Legal review
- Privacy review
- Safety review
- Accessibility review
- Security review
- Real backend review
