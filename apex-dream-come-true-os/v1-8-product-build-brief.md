# v1.8 Product Build Brief

Dream-first priority: building the Dream Come True app is always the highest priority.

## Objective

Return from GitHub and governance work to the product itself by improving the mobile Dream Intake and Dream Pathway experience.

## Product User Story

As a dreamer, parent, guardian, teacher, mentor, or reviewer, I can enter a dream in a few words and immediately see a safe first pathway with strengths, blockers, resources, risks, and next action.

## v1.8 Product Scope

- Mobile-first dream intake
- User mode selector
- Dream clarity helper
- Generated pathway card
- SWOT snapshot
- Consent and no-send gate
- Local case JSON mock export

## Product Priority Stack

1. Build the app.
2. Make it useful for real dreamers.
3. Keep children, families, and vulnerable users safe.
4. Preserve consent, privacy, and truth boundaries.
5. Use GitHub, evidence, and review gates only to support app delivery.

## Boundary

This is a static product prototype. It is not deployed, not validated, and does not send external outreach.
