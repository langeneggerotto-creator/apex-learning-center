# v1.9 Componentized App Shell Brief

Dream-first priority: building the Dream Come True app is always the highest priority.

## Objective

Move from a single prototype page to a componentized local app shell with reusable screens and local state.

## Screens

- Dream Intake
- Dream Pathway
- SWOT Snapshot
- Consent / No-Send Gate
- Local Case JSON

## Product Flow

Dreamer enters dream -> app creates local draft pathway -> app shows first actions and risks -> app blocks external sending -> app preserves a local JSON artifact for review.

## Boundary

Static local prototype only. Not deployed. Not validated. No external outreach sending. No viral outcome claim.
